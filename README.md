## ✨ Sobre o projeto

O repositório reúne as páginas `caso01.html` a `caso08.html`, arquivos de estilo, imagens e PDFs. O primeiro estudo apresenta o título “Cara de Brasil”.

## 🧰 Tecnologias

`HTML` · `CSS` · `Bootstrap` · `Material Design for Bootstrap`

## 🚀 Como visualizar

Como são páginas estáticas, abra `caso01.html` até `caso08.html` no navegador ou sirva a raiz do repositório com um servidor web local para carregar corretamente os recursos.

## 📁 Estrutura

- `caso*.html` — páginas dos estudos
- `assets/` — estilos, fontes e imagens
- `pdfs/` — documentos de referência
